# 2026-11-07

## TP55 Console（EPZ TP55 本地调音台）

用户需求：官方驱动网页 `peq.epzsz.com` 不好用且要登录，希望有本地桌面程序替代；电脑已连接 TP55。

### 逆向结果（官方前端为 Vue + WebHID）

- 设备：VID `0x3302` / PID `0x4383`，HID Report ID `0x4B`，帧长 64 字节
- SDK 模块在 `app.js` 的 `a4fa` webpack 模块内，芯片 CB 系列，采样率固定 96 kHz，biquad 系数 Q30 定点
- EQ 段报文 36 字节：`01 09 18 00 <seg> 00 00 <20B coeff> <freq u16> <q*256 u16> <gain*256 i16> <type> <offset> <tag>`
- 生效：`01 0A 04 00 00 FF FF`；写 Flash：`01 01 00`；保存槽位：`01 04 00 00 00 00`
- 可读：版本 `80 0C`、滤波器 `80 11`、工作模式 `80 1D`、输出模式 `80 19`、麦克风 `80 02 00`
- node-hid 缓冲区含 report id，所有响应解析偏移比 WebHID 代码 +1（踩过坑）
- 完整协议记录在 `docs/protocol.md`

### 交付

- Electron 45 + node-hid，无框架前端（Canvas 绘制频响曲线）
- 功能：10 段 PEQ（拖拽/滚轮/双击）、预设、EqualizerAPO 导入导出、DAC 滤波器/工作模式/增益/声道平衡（状态读回）、麦克风增益、日志
- 实时调节只写寄存器 + 刷 DSP 内存，点“保存到设备”才写 Flash
- 打包：electron-packager，产物 `dist/TP55 Console-win32-x64/TP55 Console.exe`，精简 locales 后 316MB
- 已实测：写入 1000Hz/Q1/+6dB 读回一致、saveBands 落盘、状态读取、打包版运行

### 环境注意

本机 WorkBuddy 设置了 `ELECTRON_RUN_AS_NODE=1`，启动 Electron 必须 `env -u ELECTRON_RUN_AS_NODE`，否则 `require('electron')` 为 undefined。
