# TP55 Console 迭代规划

> 定位：**个人自用 + 学习研究的本地工具**。不是官方软件的替代品，不提供官方数据，不绕过任何登录或授权。

## 一、边界与合规

先把红线定清楚，后面所有功能都在这个范围内做：

| 事项 | 做法 |
| --- | --- |
| 官方 EQ 数据 | **不抓接口、不逆向登录、不内置官方预设库**。只支持用户自己粘贴/导入文本（EqualizerAPO、AutoEQ、本工具 JSON） |
| 第三方程序 | **不捆绑、不分发 SoundKeeper**。只参考其公开原理，自己实现「音频流保活」 |
| 商标与名称 | 界面只写设备型号用于说明兼容性，不暗示官方关联 |
| 免责声明 | 保留，补充「自用/学习」定位 |
| 数据 | 全程离线，不采集、不上报 |

## 二、功能规划

### P0 本次实施

1. **顶部工具栏**
   - 设备状态灯 + 采样率徽标
   - 防吞音开关（Windows）
   - 测试音
   - 导入 / 保存
   - 让高频操作一眼可见，不藏在二级页面

2. **防吞音（Windows 专有）**
   - 原理同 SoundKeeper：持续向默认输出设备送一路静音流，避免 DAC 空闲降噪/休眠导致的开头吞音
   - 自研实现：生成 1 秒静音 WAV → 后台 `SoundPlayer.PlayLooping()` 保活
   - 开关可持久化，状态栏显示运行中
   - 独占模式下自动失败但不影响播放器，只提示

3. **设备信息页扩充**
   - 采样率 / 位深 / 声道（读 MMDevice 端点格式，2 秒刷新）
   - UAC 版本（从 `USB\Class_01&SubClass_xx&Prot_xx` 判断 1.0 / 2.0）
   - 连接方式（USB 直连 / 序列号 / 端口）
   - 固件版本（HID 读取，已有）

4. **导入能力**
   - 文件导入（已有）：`.json` / `.txt`
   - 新增「粘贴导入」：直接粘贴 AutoEQ / EqualizerAPO 文本
   - 明确提示：只接受用户自己提供的参数文本

5. **界面重排**
   - 顶部工具栏 + 信息条分层
   - 曲线区域放大，节点更好点按
   - 频段表格精简列，行内直接可编辑
   - 右侧面板：预设 / 选中段 / 快捷操作三段式
   - 空状态与操作提示更明确

6. **测试音**
   - 正弦（可调频）、粉噪、左右声道检查
   - 5 秒自动停止，播放时显示电平提示
   - 用于验证 EQ 效果与声道

7. **README 精简**
   - 去掉「替代官方」「不用登录」类表述
   - 强调自用与学习，缩短到一屏

## 三、已知问题与修复

| 问题 | 处理 |
| --- | --- |
| 保存过程 1 秒窗口内继续改动会丢失 | 保存期间锁定编辑并提示 |
| 设备断开后仍可点保存 | 顶部状态 + 按钮禁用 |
| 关闭窗口无未保存提醒 | 关闭前检查 dirty（本地已自动保存，改为提示「已保存到本地，未写入设备」） |
| 多开导致 HID 争用 | 单实例锁 |
| 采样率显示与实际不符 | 只显示系统端点格式，标注「系统混音格式」 |
| 防吞音与播放器独占冲突 | 捕获异常，静默降级，只在日志记录 |

## 四、验收标准

- 工具栏四个入口均可操作，状态实时
- 防吞音开启后进程常驻，关闭后立即释放
- 设备页采样率随系统设置变化在 2 秒内更新
- 粘贴 AutoEQ 文本能正确导入 10 段
- 测试音可听、可停、不残留
- 原有 EQ 读写、保存、预设功能不回归
