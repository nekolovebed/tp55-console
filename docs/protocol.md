# EPZ TP55 HID 协议速查

> 通过逆向官方 `peq.epzsz.com` 的 CB 芯片 SDK 得到，仅用于自制本地控制工具。

## 设备

- VID `0x3302` / PID `0x4383`（TP55）
- HID 接口 MI_00，usagePage 0x0C usage 0x01
- Report ID `0x4B`，每帧 64 字节（首字节为 report id，其余补 0）
- 设备没有按段读取 EQ 的接口，只能读回"当前段 / 最近写入段"

## 帧格式

写入类：

```
[0x01, cmd, len, 0, payload...]
```

读取类：

```
[0x80, cmd, ...]
```

响应（node-hid 缓冲区包含 report id，故比 WebHID 偏移 +1）：

```
[0x4B, 0x80, cmd, 0x00, value...]
```

## EQ 段写入（36 字节）

| 偏移 | 内容 |
| --- | --- |
| 0 | 0x01 |
| 1 | 0x09 |
| 2 | 24（coeffs 字节数 20 + 4） |
| 3 | 0 |
| 4 | 段号 0..9 |
| 5-6 | 0 |
| 7-26 | 5 × int32 LE：b0, b1, b2, -a1, -a2 |
| 27-28 | 频率 Hz，uint16 LE |
| 29-30 | Q × 256，uint16 LE |
| 31-32 | 增益 dB × 256，int16 LE |
| 33 | 滤波器类型：1 LS / 2 PK / 3 HS / 4 LP / 5 HP |
| 34 | 全局前置增益（offset），int8 |
| 35 | EQ tag（默认 1） |

## biquad 系数

- 采样率固定 **96 kHz**
- 定点为 **Q30**（乘 2^30 后取整）
- 类型按 RBJ Audio EQ Cookbook 计算，系数顺序 `b0, b1, b2, a1, a2`（a1/a2 取反）

## 常用命令

| 功能 | 报文 |
| --- | --- |
| 读固件版本 | `80 0C` → 从第 4 字节起为 ASCII，如 `1.4` |
| 读当前段 / tag | `80 09 00` |
| 写入全部段后生效 | 每段写入后 `01 0A 04 00 00 FF FF` |
| 写入 Flash | `01 01 00` |
| 保存到 EQ 槽位 | `01 04 00 00 00 00` |
| 麦克风增益 | `01 02 02 80 <offset>` |
| DAC 增益 | `01 03 02 00 <value>` |
| 数字滤波器 | `01 11 01 <1..5>` |
| 滤波器工作模式 | `01 1D 01 <0/1>` |
| 输出增益模式 | `01 19 01 <0..2>` |
| 声道平衡 | `01 16 04 <ch> <?> <value> 00` |
| 读滤波器 | `80 11` → value = 1..5 |
| 读工作模式 | `80 1D` → value = 0/1 |
| 读输出模式 | `80 19` → value + 1 = 1..3 |
| 读麦克风增益 | `80 02 00` → value，int8 |

## 注意

- 频繁写 Flash 会磨损，实时调节只写寄存器 + `01 0A 04 ...`，保存时才 `01 01 00`。
- 官方保存流程为：写 10 段 → 刷内存 → 延时约 1s → 刷 Flash → 写 `01 04`。
